# Spreadwatcher – cTrader Research Tool

Personal application for quantitative trading research, historical market data analysis,
backtesting and integration with the cTrader Open API.

Spreadwatcher records bid and ask prices of the owner's own trading accounts and compares
spreads between brokers and accounts. Access to cTrader is read-only (symbol lists and spot
prices) and only after explicit authorisation through the official cTrader OAuth process.
Spreadwatcher does not place orders, is not a broker and gives no investment advice.
